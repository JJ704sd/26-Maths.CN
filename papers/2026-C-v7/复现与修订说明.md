## 复现
使用Python 3.12，在本目录执行：
python -m pip install -r requirements.txt
python 完整代码/问题1/求解代码/求解问题1.py --仅计算
python 完整代码/问题2/求解代码/求解问题2.py --仅计算
python 完整代码/问题3/求解代码/求解问题3.py --仅计算
python 完整代码/问题4/求解代码/求解问题4.py --仅计算
python 补充实验/run.py
python qa/verify.py

上述主入口会覆盖包内各问数值结果，建议先复制本包再复算。输入数据不被修改。本次新增实验已实际执行；主流程沿用此前完整复现结果，本轮没有再次重跑四问默认入口。
主代码不带“--仅计算”会调用原Node导出程序，另需Node.js和@oai/artifact-tool。五份Excel已随包提供，不要求先配置导出环境。requirements仅覆盖数值重算及校验，不包含可选绘图环境。

## 结果表费用口径
原结果工作簿“全天购电费”列存放包含紧急购电的实际总费；滚动结果的计划页和调整页该列均为同一实际总费。论文已另外分开原计划费、合同结算费和紧急费，因此不能把工作簿该列直接当作论文的合同费。表内电量与正文指定日期一致。本版保留原模板和原数值，避免修改一个口径却留下另一个版本的结果。
