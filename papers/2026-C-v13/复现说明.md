# 第十三版复现说明

解压支撑材料 ZIP 后，在其根目录执行：

```text
python restore_data.py
python -m pip install -r requirements.txt
python qa/verify.py
python qa/verify_v11.py
```

支撑包使用标准 ZIP 容器内的 LZMA 压缩，建议用支持 ZIP-LZMA 的 WinRAR 或 7-Zip 解压。为在20MB内保留逐时证据，包内 csv.gz 按原始 CSV 字符串逐列压缩保存，相同数据列仅存一份；重复输入也仅存一份。可往返的浮点列以64位字节重排及相近列可逆异或差分保存，少量非标准文本形式另存原字符串；恢复后逐字节核对原CSV哈希，未降低精度、未截断小数。restore_data.py 按原始列顺序、表头及换行符无损拼回 CSV，并在原位置恢复所需 gzip 文件并复制重复输入，逐份核对未压缩内容的 SHA-256，不改动任何数值。恢复前后的 gzip 文件头可以不同，解压内容完全相同。恢复后的体积大于 ZIP 文件体积属于正常现象。

本地第十三版目录已经包含完整数据，无需恢复。支撑包中保留所用原始附件和原始结果模板，便于离线核验；题目原始数据本身不作为自主采集数据。

## 图与论文

```text
python figures/redraw.py

python figures/rebuild_overview.py
xelatex -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex

```

redraw.py重建四幅图，enrich.py生成九幅图，rebuild_overview.py重建流程图与月度汇总图，合计15幅编号图。新图来源与哈希在qa/new_figure_sources.json，原始压缩字节哈希用于记录本地基线，包内数据恢复以数据恢复清单中的未压缩内容哈希为准。
