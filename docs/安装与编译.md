# Windows 安装与编译

## 安装 XeLaTeX

已有 TeX 发行版时先运行 `xelatex --version`，能运行则优先复用。没有时可在 PowerShell 中使用：

```powershell
winget install --id MiKTeX.MiKTeX --exact --source winget --scope user
```

也可从 [MiKTeX 官网](https://miktex.org/download) 获取安装器，选择当前用户安装。安装后重新打开终端或编辑器，运行 `xelatex --version`。新电脑仍需自行安装，本仓库不捆绑二进制、系统字体或个人配置。

本项目测试环境为 MiKTeX 25.12，XeTeX 4.16；不要求所有机器锁定该版本。下载或安装失败时不要盲目重试，可核对官方下载地址、网络和安装日志。手动镜像下载应核对安装器摘要与可信发布清单。

## 宏包与镜像

默认源较慢时，可将 MiKTeX 宏包源设为清华 CTAN 镜像：

```powershell
mpm --set-repository=https://mirrors.tuna.tsinghua.edu.cn/CTAN/systems/win32/miktex/tm/packages/
miktex packages update-package-database
```

模板使用 ctex、xecjk、geometry、amsmath、amssymb、graphicx、float、titlesec、booktabs、array、xcolor、listings 等宏包。MiKTeX 包名不一定与 sty 文件名完全相同；按缺包提示安装，已安装包无需重复安装。可信模板首次编译可加 `--enable-installer` 按需安装，平时使用 `--disable-installer` 避免隐式下载。见 [官方宏包管理说明](https://docs.miktex.org/manual/miktex-packages.html)。

## 复制并编译国赛模板

从仓库根目录执行，选择尚不存在的目标目录；不要覆盖已有论文：

```powershell
New-Item -ItemType Directory -Path work -Force | Out-Null
Copy-Item -LiteralPath skills/5writing/templates/zh/cumcm-latex -Destination work/paper -Recurse
Set-Location work/paper
xelatex --enable-installer -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
if ($LASTEXITCODE -ne 0) { throw '首次编译失败，请查看 main.log' }
xelatex --disable-installer -no-shell-escape -interaction=nonstopmode -halt-on-error main.tex
if ($LASTEXITCODE -ne 0) { throw '第二次编译失败，请查看 main.log' }
```

输出为当前目录 `main.pdf`。两遍编译用于稳定交叉引用。从入口目录执行，LaTeX 图片路径相对于该目录，而不是 sections 子文件。正式使用前检查源码及调用的文件，不启用 shell escape 来绕过未知错误。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 找不到 xelatex | 重开终端；当前用户默认程序目录通常位于 `%LOCALAPPDATA%\Programs\MiKTeX\miktex\bin\x64`，核对实际安装路径与 PATH |
| 找不到 ctexart.cls 或 sty 文件 | 安装对应缺包，或对可信源码使用一次 `--enable-installer` |
| 图片路径错误 | 从 main.tex 所在目录编译；检查路径大小写和实际文件 |
| 卡在 Menlo 字体查找 | 本地国赛模板已改用 Windows Consolas；其他模板检查字体配置 |
| SimHei 粗体回退提示 | 检查 PDF 标题显示；本次测试回退为常规黑体，未出现缺字。不要仅隐藏警告 |
| PDF 有空白页、标题与表格分离 | 渲染逐页检查并定位强制换页，不以退出码 0 代替版式验收 |
