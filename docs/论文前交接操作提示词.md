# 论文前交接操作提示词

将下面方括号内容替换后整段发送。输入可以是队友零散材料或既有交接包；输出使用独立的新目录。此任务止于论文准备，后续再启动写作。

```text
请读取【仓库绝对路径】/skills/mathmodel-handoff/SKILL.md，按其 references/package-spec.md 完成数学建模论文前的交接准备。

任务信息：
- 竞赛和题目：【名称、年份、题号；未确定则写未确定】
- 材料目录：【题目、代码、数据、图表及笔记所在的绝对路径，可列多个】
- 新交接目录：【独立输出绝对路径，不得覆盖输入或旧交接包】
- 模式：【编程手打包／论文手验收／更新已有包；不确定则自行判断】
- 旧包或已有论文目录：【绝对路径；没有则写无】
- 队伍已确认的模型选择、最终结果版本及特殊限制：【填写；没有则写暂无】

目标是得到供论文手使用的完整准备包，保留 Python、Notebook、MATLAB 原语言，支持 CSV/Excel 和已有图表；不把代码翻译为另一种语言，不起草论文正文。先检查实际材料，能查明的事实自行查明，不要求我先补一份标准报告。

按小问整理模型公式、符号与单位、代码实现位置、数据字典与处理过程、全精度结果、作图源数据与脚本、运行记录、证据索引和缺项。区分队伍说明、代码可证明的实现和待确认推断，不编造模型理由、数据、结果、引用或实验。截图只能支持能实际读出的内容，不猜测精确数值。

把题目规定的输出范围、时间点、对象、精度和结果模板映射到实际结果；记录情景编号及比较口径。几何或分段模型补齐坐标、角度、分支和边界条件；优化保留决策明细、约束核验及求解状态，不把启发式最好结果称为全局最优。必要的基线、灵敏度或边界验证按预算执行，没做的写入缺项。给出有证据 ID 的摘要候选事实，不生成摘要正文。

若为国赛，读取 references/cumcm-case-lessons.md，核查适用年份的官方要求。在 HANDOFF 中列内部材料到拟提交支撑文件及附录的映射，以及匿名、完整代码/交互操作、包大小和 AI 披露材料的待检查项。内部交接包不自动作为参赛包；未生成最终文件时相关检查标未验证。案例只借鉴证据组织，不复制其数值、文字和图表，不自动提交任何材料。

允许运行原流程和另建轻量验证脚本。复用已有环境，检查运行副作用，在独立目录保存新结果。所有计算共用 15 分钟墙钟预算，每个进程受剩余时间限制；超时停止本次启动的计算、保存证据并继续整理报告。不自动启动付费计算。缺环境或预算不足时给出环境要求与待跑命令，不声称已运行。改变核心模型、目标、约束、数据划分或采用的参数方案前，先提出具体变更等待确认；不依赖该决定的部分继续完成。

严格遵循交接包规格的路径和字段，生成 HANDOFF.md、manifest.csv、reports/RESULTS_REPORT.md 及关联报告；有运行时保存 runs，有实际图表时保存 figures，结果和作图数据放在 code/outputs。原始文件保留来源及哈希，派生文件记录生成方法。没有的内容明确列缺项，不用空文件或虚构输出填充目录。

验收时逐项标记通过、失败或未验证，并引用实际证据；队友提供和本次复现分开记录。程序能运行不等于模型正确。遇到结果冲突保留来源并追查，不能挑选更好看的结果。允许部分交接，但必须明确哪些结论可用于写作、哪些仍待验证、哪些问题阻塞相关章节，以及谁需要补充什么、如何判断补齐。

如为更新，保留旧包，比较版本并标记受影响的证据、公式、图表和已知论文位置；不重跑无关实验。如为验收既有包，保留原记录并追加独立验收结果。记录本次真实 AI 辅助和人工待确认项。

完成后检查路径、哈希、证据定位、数值与单位、图表来源、状态和预算记录的一致性。最后给我：交接入口链接、总体状态、按小问的可用成果与阻塞项、实际执行的检查、尚未运行的命令，以及交给 5writing 的材料路径。下一阶段默认 LaTeX＋PDF，先确认模型理解与提纲再逐节起草；本次不要自动开始正文。
```

进入写作时可发送：

> 请读取【仓库绝对路径】/skills/5writing/SKILL.md，以【交接包绝对路径】/HANDOFF.md 为入口，阅读结果报告、证据表和缺项清单。沿用已核验的对应版本，复核新增或受影响内容，未验证项保持显式标记。先给出模型理解、可写范围和提纲供我确认，再逐节写作，默认 LaTeX＋PDF。
