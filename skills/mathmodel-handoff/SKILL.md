# 数模论文前交接准备

目标是让论文手能够定位每个结论的模型、数据、代码和运行证据。默认保留原语言与文件，输出独立交接目录；接收既有交接包时核验其证据，不将打包者的通过标记直接当作验收结果。

开始时读取 [交接包规格](references/package-spec.md)。用户当前要求优先；默认支持 Python、Notebook、MATLAB、CSV、Excel 和已有图表。其他输入按实际能力处理，不能读取的内容列为缺项。跨语言重写需单独确定需求，不通过重写绕过缺失的 MATLAB 环境。

国赛材料另读 [案例与规则依据](references/cumcm-case-lessons.md)，区分官方要求、案例观察和本项目建议。案例只用于判断需要准备什么证据，不直接移植到当前题目。

## 执行

1. **盘点与定位**：检查题目各小问、原始数据、代码入口、依赖、笔记、参数、日志、结果及其版本。区分编程手打包、论文手验收、已有包更新三种任务；未指定时根据输入自行判断。能从文件查明的事实自行读取，只询问影响模型含义或采用结果的决策。
2. **保留来源**：建立文件清单及 SHA-256，给数据、运行、结果和结论稳定的标识。输出路径不得覆盖输入。原始文件留存，只在独立目录生成转换表、适配脚本与新结果。可迁移交付需要包含允许复制的依赖材料；不能复制时明确外部依赖及获取方式，不能声称包可独立复现。
3. **解释模型与准备数据**：按小问整理公式、符号、单位、参数来源、算法和实现位置。代码能证明实现，不能证明队伍动机；推断与队伍确认分开标注。清洗与格式转换记录字段、类型、单位、缺失值、行数变化及规则，保留原精度。不得自行改变样本筛选、数据划分、目标函数、约束、核心算法或采用的参数方案；需要变更时列出具体差异等待确认，继续无关部分。
4. **限时复现**：先检查入口及相关调用的明显副作用，复用已有环境。原流程及轻量验证的计算墙钟时间合计默认不超过 900 秒，整个调用共享预算，不按小问重置。每次启动前计算剩余预算并设置超时；控制自己启动的子进程，超时后终止其计算并保存日志，不结束无关进程。无法约束长任务时不启动。材料阅读与报告编写不计入计算预算。不得自动使用付费计算；缺环境、超预算或需要未经授权变更时记录未验证及待跑命令，不用低配试跑冒充正式结果。
5. **组织结果和图表**：保留队友结果与本次结果两套来源。记录比较规则、容差及理由，不强求随机模型逐位一致。冲突时追查数据、参数、种子和环境，不挑选更好看的结果。每张拟用图保留源数据、生成脚本、标签单位和图注要点；只有图片且无法重建时保留原图并标注限制，不从截图编造精确数据。
6. **验收与交接**：按规格逐项填写检查方法、实际证据和状态，允许部分交接。输出能支持的结论、禁止当作已核实事实的内容及可执行补项。不要把程序退出成功等同于模型正确。记录本次实际 AI 辅助、人工待确认项和更新影响，不生成虚假工具记录。

## 进入写作与更新

交接前在已有报告中检查小问要求覆盖、情景比较口径、边界/约束证据和摘要候选事实，具体记录见规格。国赛另在 `HANDOFF.md` 给出内部材料到匿名参赛支撑材料的映射及待检查项；内部可交接不等于可直接参赛提交。

以交接目录作为后续工作根目录，向 `5writing` 提供 `reports/RESULTS_REPORT.md`、证据索引和相关图表；已有写作工程则提供明确路径映射，未经授权不覆盖论文材料。写作阶段仍需确认模型理解和提纲，保留其逐节起草流程。本 Skill 不起草正文，也不宣称通过论文最终验收。

队友更新材料时保留旧包，生成新版本并比较文件哈希与证据关系；标记受影响的结果、公式、图表及已知论文位置待复核。不因打包时间改变全部证据标识，也不重新运行无关实验。

结束时给出交接入口、总体状态、已核验范围、阻塞项、剩余复现工作和进入写作的明确路径。完整操作提示词见仓库 `docs/论文前交接操作提示词.md`；独立使用本 Skill 不依赖该文档或其他 Skill。
